5. EXPLAINABILITY IMPLEMENTATION
================================================================================

Grad-CAM Implementation:
[x] Implemented? Yes
[x] Average generation time: 1.03 seconds (on CPU)
[x] Any modifications to standard Grad-CAM? Yes (Percentile-based thresholding 
    retains only the top 18% of activations [>= 82nd percentile], scales by power-law 
    [exponent=0.65] to amplify dimmer regions, and applies a Gaussian Blur with 
    radius=7 for smoothing before compositing onto grayscaled scans).

LIME Implementation:
[x] Implemented? Yes
[x] Number of superpixels used: 50
[x] Number of perturbed samples: 120
[x] Average generation time: 2.25 seconds
[x] Any modifications? Yes (Custom K-Means SLIC segmentation segment boundaries 
    with compactness 15.0 and max iterations 4 to bypass scipy/skimage dependencies. 
    Uses Ridge Regression [L2 regularization, lambda=1.0] instead of Lasso).

SHAP Implementation:
[x] Implemented? Yes
[x] Type (TreeExplainer/KernelExplainer/DeepExplainer): Integrated Gradients (Path SHAP variant)
[x] Average generation time: 5.58 seconds
[x] Any modifications? Yes (Evaluates 20 path steps between an all-zero baseline tensor 
    and the input image, calculates average gradients, applies power-law scaling [0.5], 
    and applies a Gaussian Blur [radius=5] to clean attribution noise).

8. UNIQUE FEATURES & INNOVATIONS
================================================================================

[x] Describe any novel techniques you implemented:
    - Side-by-side Explainability Hub offering 3 discrete attribution viewpoints
      (Grad-CAM for coarse areas, LIME for superpixels, SHAP for fine margins).
    - Diagnostic Chat Advisor built directly into the sidebar that leverages classification
      outputs to provide clinical action recommendations.
    - PDF Report Generator compiling diagnostic class, confidence metadata, and the 
      Grad-CAM visual attribution map into a clinical sheet.

[x] Did you address any specific challenges?
    - Confidence Safeguarding: A 40.0% confidence threshold. Below this, predictions 
      are masked as "Unclassified/Rare Tumor" with guidelines to prevent blind AI trust.

[x] Any custom loss functions or training strategies?
    - Two-Phase Transfer Learning: Epochs 1-5 train only the custom classification head 
      (learning rate 1e-3) with a frozen backbone, while epochs 6-15 unfreeze the last 20
      layers of the backbone for fine-tuning (learning rate 1e-4).

[x] Comparison with any baseline models? Yes
    - Deployed EfficientNet-B0 (86.38% test accuracy, 3 XAI views) compared with:
      1. Custom Vanilla CNN (82.3% test accuracy)
      2. ResNet-50 + Grad-CAM (89.5% accuracy but high parameter bloat & no LIME/SHAP).
